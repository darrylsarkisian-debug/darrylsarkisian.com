Selected work

Connecting Claude to ServiceNow

2026 · personal project

An MCP server that lets Claude look up and log tickets in a ServiceNow instance in plain language. I built it to learn the Model Context Protocol properly rather than just read about it, and I've since used it as a live demo. A smaller one in Python does the same for a Zendesk knowledge base.

Demo recording. An updated version is on the way.

A security objection with a simpler answer

NCSI · 2017–2020

A client's CTO didn't want to open up SAML for syncing users into Ivanti. Instead of pushing, I proposed a scheduled CSV export over SFTP that loaded straight into the user directory, and demoed it working. It solved his concern, and meetings with that team were easier from then on.

A product gap that became a module

Ivanti · 2015–2017

Working deals across a thirteen-state Western territory, I kept running into requests for project portfolio management that the product couldn't cover. I wrote the gap up for product development, and it was built. That write-up is credited in the PPM chapter of Kevin J. Smith's The Practical Guide to World-Class IT Management.

Evaluations against ServiceNow

EasyVista · 2022–2024

Much of my EasyVista work was head-to-head evaluations with ServiceNow. We won several of them by running proofs of concept on the customer's real processes and data instead of on a standard demo script.
